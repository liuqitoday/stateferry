# StateFerry Privacy Policy

Last updated: 2026-08-21

StateFerry is a Chrome extension for managing Cookies, localStorage, and sessionStorage in the current active tab.

## Data handled

When the user opens the extension, StateFerry can read the current page URL, Cookies matching that URL, and Web Storage belonging to that page's origin. The user can then choose to reveal, copy, edit, delete, export, or import values.

## How data is used

Data is used only to provide the current-tab storage-management and backup/migration features. Processing occurs locally in the browser. StateFerry does not send storage values, URLs, or backups to a developer-controlled server, analytics service, advertising network, or other third party.

## Storage and retention

StateFerry does not maintain an extension history or cloud copy of storage values. Values exist in the current page, in memory while the interface is open, or in a backup file only when the user explicitly exports one. The user controls exported files and should delete them when no longer needed.

## Sharing and sale

StateFerry does not sell, rent, share, or disclose user data. No human at the project maintains access to the values handled by the extension.

## Security

Sensitive values are masked by default in the interface. The extension requests no broad host access and revalidates the active tab before writes. Users should treat exported backups as sensitive credentials and store them securely.

## Contact

For privacy questions or requests, open an issue in the StateFerry repository: https://github.com/liuqitoday/stateferry/issues

This policy is intended for the StateFerry Chrome extension and may be updated when the product's data handling changes.
